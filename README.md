# BilibiliRSS

> B 站「稍后再看 · UP/合集/视频订阅追更 · 增量监控 · 下载」一体化油猴脚本（独立版，数据存本地）

![Version](https://img.shields.io/badge/version-0.2.0-pink.svg)

## 简介

BilibiliRSS 是一个运行在 [Tampermonkey](https://www.tampermonkey.net/)（或兼容油猴管理器）里的用户脚本。它把 B 站的几件事整合到一个悬浮球面板里：

- **稍后再看**：把订阅 UP / 合集 / 单视频的新投稿自动收进列表，看完一键标记完成 / 忽略 / 删除。
- **订阅追更**：支持三种订阅类型 —— `up`（UP 投稿）、`season`（合集）、`ugc`（分P 视频）；关键词可按 **AND** 逻辑精准收录、并可排除关键词。
- **增量监控**：监控 UP 的粉丝 / 关注 / 总播放 / 获赞，或监控视频的播放 / 弹幕 / 点赞 / 投币 / 收藏 / 评论等，刷新时显示变化量（Δ）。
- **下载助手**：直链（≤720P）直接落盘；更高画质自动走 DASH 分片 + 页内 ffmpeg.wasm 合并为 mp4；附带弹幕 XML 下载。

所有数据（订阅、稍后再看、监控、设置、头像缓存）仅保存在**你本机**的 Tampermonkey 存储里，不上传任何服务器。

## 功能特性

- 悬浮球 + 抽屉式面板，**全部 UI 位于 Shadow DOM**，与主站样式彻底隔离。
- 左侧栏 6 页签导航，Bootstrap Icons 实心图标，浅色 / 深色双主题。
- **高性能渲染**：列表按 key 差分复用节点、rAF 合帧只重绘可见页、事件委托、滚动分页、离屏 `content-visibility` 跳过绘制。
- WBI 签名、buvid 指纹刷新、风控（412/-352）自动重试与兜底，提升抓取稳定性。
- 订阅 / 监控并发去重、开面板刷新冷却，避免触发 B 站风控。
- 毛玻璃 toast，骨架屏与微动效，键盘快捷键 `Alt+B` 开关面板、`Esc` 关弹层。
- 数据一键导出 / 导入（JSON 备份）。

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展。
2. 点击 [`BilibiliRSS.user.js`](BilibiliRSS.user.js) 安装脚本（或把文件拖入 Tampermonkey 管理页）。
3. 脚本会在以下页面自动启用：
   - `https://www.bilibili.com/*`
   - `https://space.bilibili.com/*`
   - `https://live.bilibili.com/*`
   - `https://t.bilibili.com/*`
   - `https://manga.bilibili.com/*`

## 使用

- 右下角出现 **B 站粉悬浮球**，点击打开面板（快捷键 `Alt+B`）。
- 面板左侧栏从上到下共 6 个页签：**稍后 / 工作台 / 监控 / 订阅 / 下载 / 设置**。
- **稍后**：查看 / 标记完成 / 忽略 / 删除收进来的视频；顶部可按状态、按订阅筛选，并搜索标题或 UP。
- **工作台**：自动识别当前页面（视频 / 合集 / UP 空间），一键 **订阅 / 监控 / 下载**（支持多 P、合集批量勾选）。
- **监控**：查看 UP / 视频的数据变化；在任意 UP 空间页或视频页打开「工作台」点「监控」即可加入。
- **订阅**：管理已订阅的 UP / 合集 / 分P 视频，可编辑关键词、开关、刷新、删除。
- **下载**：独立的任务队列页，实时进度、失败原因与重试。
- **设置**：系统通知、新订阅回填条数、下载画质、附带弹幕、数据导出导入、清空。

## 数据说明 / 隐私

- 数据存于 Tampermonkey 的脚本存储（`GM_setValue`），仅本机可读。
- 抓取走 B 站公开 API，需你登录态的 Cookie 才能拿到更高画质 / 完整数据；脚本不替你登录、不上传任何数据。
- 头像以 dataURL 形式本地缓存（上限 400 个），用于减少重复请求。

## 更新日志

### v0.2.0

**界面重设计**

- 左侧栏改为 6 个独立页签：**稍后 / 工作台 / 监控 / 订阅 / 下载 / 设置**，全部用 Bootstrap Icons 实心图标，界面内不再有 emoji。
- 原「工具箱」更名 **工作台**（第 2 位），只负责当前页面的一键订阅 / 监控 / 下载。
- **下载管理**从工作台里拆出来，独立成页（第 5 位），带任务数量角标。

**性能**

- 列表改为按 key 差分渲染，节点复用、零 DOM 移动。
- rAF 合帧 + 视图脏标记，只重绘当前可见页。
- 事件委托：每个列表根节点只绑一次监听，长期开着不累积。
- 惰性渲染 + 滚动分页；离屏卡片用 `content-visibility` 跳过布局与绘制。
- 属性级写入缓存：值没变就不写 DOM。

**修复**

- 修复存储里 `dedupe` 等字段为非数组时启动崩溃、整个面板挂不上的问题。
- 修复头像本地缓存层（`faceSrc` / `warmAva`）缺失导致订阅页渲染报错、列表为空的问题。
- 修复极早期注入（`document-start`）时 `documentElement` 尚未就绪导致挂载崩溃的问题。
